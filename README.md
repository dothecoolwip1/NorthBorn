# Northborn

Northborn is a cross-platform field operations platform for trucking, hydrovac, vacuum, steaming, water hauling, environmental, construction, oilfield, and industrial service companies.

## Foundation

- React + TypeScript
- Vite
- Capacitor-ready mobile architecture
- Supabase backend
- Multi-tenant organization model
- Row Level Security
- Offline-aware application shell

This repository is the primary source of truth for the Northborn application.
